### 🛠️ Features
- 🔊 **Complete iOS Sound Set** — 43 audio files covering UI, ringtones, notifications, and alarms
- 😀 **iOS Emoji Replacement** — System-wide emoji override with high-res iOS font
- 🔤 **SF Pro Display Font** — 16 font weights (Regular to Ultralight, with Italic variants)
- 🏭 **OEM Detection** — Auto-detects Samsung, Xiaomi, OnePlus, and other OEM emoji fonts
- 🔄 **Anti-Revert System** — Blocks Google Play Services from re-downloading stock emoji fonts
- 📘 **Meta App Fix** — Replaces Facebook, Instagram, and Messenger emojis

### ⚙️ Technical Specifications
- **Type:** Root Module (Systemless)
- **Compatibility:** Android 11 to 16
- **Architecture:** Dual-path installation (`/system/product/` and `/system/media/`)
- **SELinux:** Full `u:object_r:system_file:s0` context enforcement

### 🚀 How to Install and Run

```bash
# 1. Download the latest .zip from the Releases page
# 2. Open Magisk, KernelSU, or APatch manager
# 3. Flash the .zip via "Install from storage"
# 4. Reboot your device
```

> ⚠️ **Warning:** The module clears the Gboard emoji cache during installation. You may notice a brief delay on the first keyboard launch.

- **Tipo:** Módulo Root (Systemless)
